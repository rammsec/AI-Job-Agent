A more focused way to explore your next role.

AI Career Agent is a personal project exploring how resume extraction, candidate skills, and structured job listings can come together in a private, locally run job-search assistant.

Prototype in active development

What it does

The prototype extracts text from a resume, builds a simple keyword profile, and compares that profile with jobs returned from configured sources. Matching results are ranked and stored locally for review.

Current capabilities

PDF, DOCX, and TXT resume parsing
Candidate keyword profiling
Adzuna Australia API adapter
Local SQLite match history
Browser-based local workbench
Automated test suite
This is an independent personal software project, not an employment agency and not affiliated with or endorsed by Adzuna. Resume files and match history are processed locally; job-search requests are sent to the configured source when a scan is run.
